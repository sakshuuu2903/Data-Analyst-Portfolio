# E-commerce Sales Analysis using SQL

## Project Overview

This project focuses on analyzing e-commerce sales data using SQL.
The objective is to extract meaningful business insights by performing data analysis on sales and profit data.

## Tools & Technologies

- SQL
- SQLite
- Data Analysis
- Aggregate Functions
- Window Functions

## Business Questions

- What is the total revenue generated?
- What is the total profit?
- Which category has the highest sales?
- Which category generates the highest profit?
- What are the top-selling products?
- Which products are most profitable?
- How do products rank based on sales?

## Key Insights

- Total Revenue: 466,500
- Total Profit: 54,300
- Total Orders: 30
- Office category generated the highest sales.
- Office category generated the highest profit.
- Laptop was the top-selling product.
- Product performance was analyzed using RANK() and ROW_NUMBER() functions.

## SQL Concepts Used

- SELECT
- SUM()
- COUNT()
- AVG()
- GROUP BY
- ORDER BY
- LIMIT
- RANK()
- ROW_NUMBER()
- PARTITION BY
