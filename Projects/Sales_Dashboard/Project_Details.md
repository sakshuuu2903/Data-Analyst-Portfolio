# Sales Dashboard Project

## Objective
To analyze sales data and create an interactive dashboard using Excel and Power BI.

## Tools Used
- Microsoft Excel
- Power BI
- Data Cleaning
- Data Visualization

## Data Cleaning
- Removed duplicate values
- Checked missing values
- Prepared data for analysis

## Analysis Performed
- Sales analysis
- Profit analysis
- Category-wise performance
- State-wise sales comparison

## Dashboard KPIs
- Total Sales
- Total Profit
- Total Orders
- Average Sales

## Outcome
Created an interactive dashboard to understand business performance and generate insights.
