# Sales Dashboard - Data Analyst Project

## Project Overview
This project is a Sales Dashboard created to analyze sales performance and generate meaningful business insights using Excel and Power BI.

## Tools & Technologies
- Microsoft Excel
- Power BI
- Data Cleaning
- Data Analysis
- Data Visualization

## Dataset Details
The dataset contains:
- Order Information
- Customer Details
- Product Details
- Sales Data
- Profit Data
